# PATRA 

## Description - 
 its an open source Notes app with  prehistoric pirate theme its preety cool here you can write your notes save your notes and can Demolish notes too it has all the Features as a Basic NotesApp do but its a lil different

# Journey (How i made it ) - 
- **VERSION 1 - I made this Project as my first ever React + Tailwind Project .. in this Project i used hooks such as useState to change the State of the scroll everytime user click on the scroll i used map to map the input into the scrolls as an Array i used multiple useState hooks to manage many many states like when user close the scroll when the user open the scroll and also added a welcome scroll for anyone who is going to use my app**
- **VERSION 2 - For the version 2 i added a mini game or achievment system that everytime you add 3 scrolls you will get a brand new scroll for this i add an Array of images with different styles and also added another useState hook to change the scrolls  i added a logic that counts how much time a person clicked the Add Notes button and if its three time then only the Scroll changes**
- **VERSION 3 - For the Version 3 i added Some pirate scroll Background With Pirate Scroll ui not only that i also added A " Demolish" option that helps you delete your notes with the splice Array method after that i also Added the localStorage system so that your notes stays intact with the app and here i learned another hook named useEffect to Set the task in localStorage and convert it to string then i added a LoaderFunction and used it to save my task and Parsed and Converted that into an Array and returned it This Part made me thinking as i had to go out of my main Function**
- And at last i added an aler msg after getting new scrolls
